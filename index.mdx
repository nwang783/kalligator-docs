Kalligator is a local-first desktop harness for cyber Agent work. It runs supported Agent harnesses, keeps durable Chat history, and adds domain capabilities through Packages.

You can use one Project to coordinate Chats, evidence, research records, and local tools. The control plane stores shared state. The Worker keeps harness execution and machine access local.

<Warning>
  Use Kalligator only for systems and applications that you are authorized to test.
</Warning>

## What Kalligator owns

- **Projects** group related Chats, files, and Package state.
- **Chats** keep resumable Agent history and tool provenance.
- **Packages** add domain guidance and bounded commands.
- **Project Records** store structured Package data.
- **Blobs** store immutable file content by hash.
- **Resource Locks** prevent conflicting use of local devices and capture tools.

Kalligator does not place unrestricted host access inside an Agent container. Package commands define the allowed execution boundary.
